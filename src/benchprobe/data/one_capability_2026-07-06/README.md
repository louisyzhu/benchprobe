# one_capability_2026-07-06

`aa_analysis_models.csv` is the analysis-ready table behind *One Capability or Many? Testing the
Economic Validity of Frontier AI Evaluation* (Zhu, 2026, arXiv:2608.29420), copied unchanged from
`data/processed/` of https://github.com/louisyzhu/frontier-ai-economic-validity at commit
`946ce845`. `MANIFEST.json` records its SHA-256 and the hashes of the upstream snapshots it was
derived from; the smoke test checks the hash, and `benchprobe.io` will check it on every load (T2).

The table is derived data released under CC BY 4.0 by its author. The capability and price figures
in it originate with Artificial Analysis (Models Leaderboard, captured 2026-07-06T15:17:51Z) and the
model metadata with Epoch AI (Notable AI Models, CC BY 4.0, captured 2026-07-06T15:19:56Z). Neither
upstream source endorses this package or the papers it supports. The raw snapshots themselves are
not vendored; they remain in the source repository under their upstream terms.
